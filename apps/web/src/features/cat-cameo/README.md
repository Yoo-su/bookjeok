# Frontend Feature: Cat Cameo (가끔 나타나는 검정고양이)

독서 키재기 맨 위 책에 앉은 검정고양이가 특정 기능과 상관없이 북적 어디서든 가끔 나타납니다. 화면 틀(상단바, 화면 아래 모서리)을 넘나드는 것이 요점입니다. 서버·DB 없이 프론트에서만 동작합니다.

## 폴더 구조

```
cat-cameo/
├── constants.ts                      # 장면 목록, 빈도 규칙(CAMEO_RULES), 조용히 할 경로
├── lib/
│   ├── schedule.ts                   # 나올지·어느 장면인지 고르기(순수 함수) (+ test)
│   ├── draw.ts                       # 걷는 옆모습·빼꼼 정면 그림 (+ test)
│   └── free-gap.ts                   # 상단바에서 멈춰 설 빈 틈 고르기 (+ test)
├── stores/use-cat-cameo-store.ts     # 오늘 나온 횟수·마지막 장면 (localStorage)
└── components/
    ├── host/cat-cameo-host/          # 언제 띄울지 판단. [locale]/layout에 붙어 있음
    └── scenes/
        ├── header-walk/              # 상단바 알약 안을 걸어 지나감
        ├── bottom-peek/              # 화면 아래 모서리에서 빼꼼
        └── cat-cameo.stories.tsx     # 장면 반복 재생·정지 자세
```

## 장면

- **상단바 산책(walk)**: 상단바 알약(`[data-site-header] > div`) 안쪽 바닥을 옆모습으로 걸어 지나갑니다. 알약 둥근 끝에서 나타나 반대쪽 끝으로 사라집니다. 로고·메뉴·버튼이 없는 빈 틈에서 멈춰 고개를 돌려 이쪽을 보고, 천천히 눈을 감았다 뜬 뒤(고양이의 "편하다"는 인사) 다시 걷습니다. 걸을 때는 8프레임 스프라이트를 쓰고 멈췄을 때는 기존 정면 SVG를 보여줍니다. 알약 폭이 260px보다 좁으면 나오지 않습니다.
- **아래에서 빼꼼(peek)**: 화면 아래 왼쪽이나 오른쪽 모서리에서 귀 끝부터 올라와 갸웃하고, 눈까지 올라와 앞발로 모서리를 붙잡고, 왼쪽·오른쪽을 보고 깜빡인 뒤 쏙 내려갑니다(약 5초). 가운데의 빠른 메뉴(BottomDock)와 겹치지 않게 모서리 쪽에만 나옵니다.
- **누르면**: 산책 중이면 깜짝 뛰어 하던 방향으로 내빼고, 빼꼼이면 쏙 숨습니다. 안내 문구·만난 횟수·축하 효과는 두지 않습니다. 설명하지 않고 고양이만 둡니다(2026-11-05 결정).

스프라이트는 `apps/web/public/cat-cameo/`에 있으며 각 장면을 띄울 때 불러옵니다. 빼꼼은 다섯 표정을 쓰고, 화면 가장자리 위아래로 움직이는 효과는 별도로 적용합니다. 상단바에서 멈춰 정면을 보는 얼굴은 독서 키재기 고양이(`reading-log/.../lib/figure-cat.ts`)의 `catHead`를 공유합니다.

## 언제 나오나

`CAMEO_RULES`에서만 고칩니다.

- 페이지에 들어와 6~20초 머문 뒤 30% 확률로 주사위를 굴립니다.
- 세션(탭)당 2번, 다음 등장까지 3분, 하루 4번까지입니다. 바로 전과 다른 장면을 고릅니다.
- 쓰거나 결제하는 화면(로그인·가입·리뷰 쓰기·판매 등록·`/edit`·주문·관리자)에서는 나오지 않습니다.
- 그 순간 다른 창(`role="dialog"`)이 떠 있거나, 입력칸에 커서가 있거나, 탭이 가려져 있으면 건너뜁니다.
- 기기 설정이 "동작 줄이기"면 나오지 않습니다.

## 확인하기

- 스토리북 `Features/CatCameo/Scenes`: 장면을 반복 재생합니다. 고양이를 눌러 반응을 봅니다. `StillPoses`는 걸음 자세를 크게 멈춰 보고, `ActualSize`는 실제 헤더에 등장하는 크기로 봅니다.
- `Features/CatCameo/Scenes/OnRealHeaderAndFooter`에서 실제 헤더와 푸터를 띄우고, 버튼으로 두 장면을 바로 재생합니다. 빼꼼은 푸터의 위치와 관계없이 화면 아래 모서리에 나옵니다.
- 실제 화면에서는 주소에 `?cat=walk` 또는 `?cat=peek`를 붙이면 한도·확률 없이 0.9초 뒤에 나옵니다(기록하지 않음).

### 아기고양이 디자인 적용 (2026-11-05)

- 옆눈을 작고 수평에 가깝게 유지하면서 머리는 키우고, 몸은 짧고 둥글게 바꿨습니다. 정면·빼꼼도 같은 둥근 볼과 짧은 귀를 씁니다.
- 뒷다리 폭만 줄였던 시안은 폐기했습니다. 네 다리를 허벅지부터 둥근 발끝까지 이어진 곡선으로 다시 그렸습니다. 꼬리도 짧고 가늘게 맞췄습니다.
- 헤더 산책·정면·빼꼼과 모든 스토리에 적용했습니다. 독서 키재기의 책 위 고양이도 같은 아기고양이 얼굴로 통일했으며 공유 이미지에도 반영됩니다.
- 등장 빈도·애니메이션 시간·클릭 반응은 유지합니다.
