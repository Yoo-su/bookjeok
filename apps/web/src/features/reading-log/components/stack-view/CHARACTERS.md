# 독서 키재기 캐릭터 그리기

기본 남녀 캐릭터와 작가 캐리커처를 그리고 추가하는 방법입니다. **작가를 추가하거나 캐릭터를 고치기 전에 읽으세요.** 2026-09-26 작가 5명을 그리며 확인한 기준과 실제로 겪은 문제를 정리했습니다.

## 원칙

- **이미지 파일이 아니라 코드로 그립니다.** AI 생성 원화(WebP)로 바꿨다가 되돌린 적이 있습니다. 사실적인 그림이 무대의 손그림 책·말풍선과 어울리지 않았고, 높이별 표정·손에 든 책 색·선 떨림이 사라졌습니다. 사진이나 원화를 따라 그린 윤곽도 쓰지 않습니다.
- **모두 같은 연필로 그립니다**(`lib/pencil.ts`). 진한 선 한 번과 흐린 선 한 번을 겹치고 살짝 흔듭니다. 색은 흰 종이·먹색·회색 톤(`TONE`)만 씁니다. 유채색은 손에 든 책(가장 최근에 읽은 책의 표지색) 하나뿐입니다.
- **얼굴이 아니라 실루엣과 상징물로 알아보게 합니다.** 무대에서 얼굴은 20px 안팎이라 이목구비로는 닮게 할 수 없습니다. 인물마다 멀리서도 보이는 특징 1~2개(머리 모양·옷·소품)를 고릅니다.
- **표정은 고정입니다.** 높이에 따라 표정이 바뀌는 건 기본 캐릭터뿐입니다(`status.mood`).
- **움직임은 넣지 않습니다.** 선 떨림은 `figure.ts`가 세 벌을 그려 번갈아 보여 줍니다(`globals.css`의 `stack-boil`). 캐릭터마다 따로 애니메이션을 만들지 않습니다.
- **키는 그림으로 표현하지 않습니다.** `lib/authors.ts`의 `heightCm`로 축척이 맞춰집니다. 사르트르가 작아 보이는 것도 축척이 한 일입니다. 몸 비율(무릎 28%·허리 60%·어깨 82%, `lib/status.ts`)은 모두 같아야 말풍선의 "허리까지 9cm"가 그림과 맞습니다.

## 좌표

캐릭터는 가로 300 × 세로 1000 단위로 그리고 무대가 키에 맞춰 늘립니다. 가운데는 x=150, 머리 꼭대기가 y=0, 발바닥이 y=1000입니다. 좌우 대칭인 부분은 한쪽만 적고 `mirror`·`both`로 뒤집습니다.

| 부위           | y        | 메모                                                 |
| -------------- | -------- | ---------------------------------------------------- |
| 머리·모자 윗선 | 0~12     | 윗선을 여러 곡선으로 나눠야 헬멧처럼 보이지 않습니다 |
| 얼굴 윤곽 시작 | 58~64    | `face({ top })`                                      |

| 턱             | 146~158  | `face({ chin })`. 클수록 긴 얼굴                     |
| 목             | 120~180  |                                                      |
| 어깨           | 170~196  |                                                      |

## 부품 (`lib/figure-authors.ts`)

| 부품                                                                                | 쓰임                                                                                                           |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `trousers(p, top, tone)`                                                            | 정장 바지. 윗옷 밑단 아래로 보이는 만큼                                                                        |
| `shoes(p)`                                                                          | 끝이 둥근 구두                                                                                                 |
| `arms(p, heldColor, tone, cuff?)`                                                   | 소매·손·손에 든 책. 모든 작가가 씁니다                                                                         |
| `jacket(p, { hem, tone, vDepth, buttons, open? })`                                  | 재킷 몸판. `open`이면 앞여밈을 그리지 않습니다                                                                 |

| `neck(p, top, bottom)` · `ears(p)` · `face(p, { top, chin, half })`                 | 목·귀·얼굴 윤곽                                                                                                |
| `TONE`                                                                              | `suit`·`tweed`·`mid`(옷), `dark`(넥타이·터틀넥), `hair`·`brown`·`grey`·`silver`(머리), `coat`·`dress`(밝은 옷) |

**그리는 순서는 뒤에서 앞으로**입니다. 뒷머리·쪽머리 → 바지 → 구두 → 팔 → 몸판(재킷·코트·원피스) → 셔츠·넥타이 → 옷깃 → 목 → 깃 → 귀 → 얼굴 → 머리 → 이목구비 → 소품(파이프·담배·연기).

## 겪은 문제

- **얼굴 요소를 모자·앞머리 위에 겹치지 않습니다.** 기본 여자 캐릭터는 앞머리 네 가닥이 눈썹을 가로지르고, 놀란 표정의 눈썹이 비니 테두리 위에 올라가 지저분했습니다. 앞머리는 관자놀이 쪽으로만 흘리고 눈썹을 내렸습니다.
- **목 앞에 깃을 여러 겹 겹치지 않습니다.** 카뮈는 셔츠 깃과 세운 코트 깃이 X자로 얽혀 셔츠 깃을 뺐습니다. 한 겹이면 충분합니다.
- **원피스·코트는 허리를 잡고 밑단을 퍼지게 합니다.** 울프의 첫 시안은 어깨부터 일자로 떨어져 자루처럼 보였습니다.
- **눈동자는 눈꺼풀 선보다 아래에 둡니다.** 울프의 내리깐 눈은 눈동자가 눈꺼풀 선에 가려 눈을 감은 것처럼 보였습니다(y 103 → 105.5).
- **굵은 눈썹은 기울기를 5 이하로 둡니다.** 쿤데라는 기울기가 커서 화나 보였습니다(굵기 3 → 2.7, 기울기 7 → 5).
- **머리 광택선은 옅고 짧게 둡니다**(`hatch`에 종이색, 투명도 0.35 이하). 진하면 만화처럼 번들거립니다.
- **소품은 얼굴 윤곽·귀 바깥으로 뺍니다.** 파이프·담배 연기가 볼이나 귀를 지나면 알아보기 어렵습니다.
- **한 명을 먼저 그려 보여 주고 확인받은 뒤** 나머지를 그립니다. 방향이 틀리면 전부 다시 그려야 합니다.

## 작가 추가 절차

1. **인물 조사.** 키는 전기·인터뷰 등 출처가 있는 자료에서 가져오고, 링크를 `authors.ts`의 `source`에 둡니다. 검증된 실측이 아니므로 화면은 '약'으로 표기합니다. 생존 인물은 초상·퍼블리시티권 부담이 있어 되도록 작고한 작가를 고릅니다.
2. **레시피.** 위 표처럼 실루엣·상징물 1~2개·얼굴 값·톤을 먼저 정합니다.
3. **코드.**
   - `lib/types.ts`의 `StackAuthor`에 id를 추가합니다. 그러면 아래 두 곳은 타입 검사가 빠뜨림을 잡아 줍니다.
     - `lib/authors.ts`: `heightCm`, `source`
     - `lib/figure-authors.ts`: 그리는 함수, `drawAuthor`의 목록
   - 번역(ko·en) `reading_log.stack.authors`(전체 이름)와 `author_short`(칩에 들어갈 짧은 이름, 4자 안팎)
   - 작가 이름을 늘어놓은 문구: 번역의 `announcement.reading_stack.s3_body`, `reading_height_page.features.authors.body`, 루트 README의 독서 키재기 줄, 독서 기록 README의 「작가와 비교」
   - 따로 할 일이 없는 곳: 키 설정 팝오버 목록, 비교 무대의 칩과 도는 순서(앞 5명 뒤에 붙음), Storybook 목록, 테스트
4. **확인.**
   - Storybook `ReadingLog/StackFigures`: `AuthorFaces`(얼굴 확대), `Authors`(전신), `Lineup`(기본 캐릭터와 나란히 두고 톤 비교)
   - `ReadingLog/ReadingStack`에서 칩으로 골라 무대 축척과 말풍선, 공유 이미지 미리보기
   - `Announcement/ReadingStackIntro` 3번 장
   - `pnpm vitest run src/features/reading-log` (작가마다 다른 그림, 손에 든 책 색)

- 작가가 7명을 넘으면 비교 무대의 칩이 두 줄이 되어 무대를 가립니다. 그때는 칩 줄을 가로 스크롤로 바꾸세요.

## 홈 인사 동작 (`author-peek`)

홈 머리글 옆 인사는 같은 그림을 부위별로 나눠 움직입니다. 평소 무대 그림은 한 획도 달라지지 않게 두었습니다(인사 옵션을 켤 때만 다르게 그림).

- **머리**: `buildFigure({ peek: true })`면 연필의 `headOn()` 뒤에 그린 선이 `peek-head` 묶음이 됩니다. 새 작가도 귀·얼굴을 그리기 직전에 `p.headOn()`을 부르세요(울프처럼 뒷머리를 먼저 그리면 그 앞뒤로 `headOn`/`headOff`).
- **들어 올린 팔**: `arm: "wave" | "heart"`면 오른팔(화면 오른쪽)을 들고 팔뚝·손을 `peek-forearm`으로 따로 둡니다. 팔꿈치 `WAVE_ELBOW`를 축으로 흔듭니다. 윗팔은 재킷 밑에서 나오므로 새 작가도 `arms(…, raise)`만 넘기면 됩니다. 윗팔에 어깨선과 안쪽 선이 없으면 몸판과 팔뚝 사이 틈이 비어 팔뚝이 떠 보입니다(울프처럼 허리가 잘록한 옷에서 두드러짐). 몸 양쪽에 `both`로 긋는 선이 있으면 팔을 들 때 오른쪽이 허공에 뜨니 `raise`일 때는 왼쪽만 긋습니다(카뮈의 소매 선).
- **손하트**: 엄지·검지를 주먹보다 먼저 그려 주먹 윗선에서 엇갈리게 하고, 둥근 두 손끝만 하트의 두 볼처럼 내밉니다. 가늘고 긴 손가락이 가운데서 X자로 엇갈리면 가위처럼 보입니다. 분홍 하트(`HEART_CENTER`)를 `peek-heart`로 따로 그려 띄웁니다. 캐릭터에서 책 말고 유채색을 쓰는 유일한 예외입니다.
- **서명**: 등장한 작가의 영문 성을 머리 옆에 서명처럼 씁니다. `author-peek/signatures.ts`에 Dancing Script(SIL OFL 1.1, 기본 굵기) 22px 글리프를 경로로 바꿔 둡니다. 홈에서 폰트를 받지 않으려는 것입니다. 새 작가를 추가하면 같은 서체·크기로 `opentype.js`의 `font.getPath(성, 0, 0, 22).toPathData(1)`을 뽑아 넣으세요(기준선 y 0, 왼쪽 끝 x 0). 이름은 좌우를 뒤집는 틀 **밖**에 둡니다. 안에 두면 오른쪽에서 나올 때 글자가 거울상이 됩니다.
- **몸을 통째로 크게 돌리지 않습니다.** 첫 시안은 발끝을 축으로 45도까지 휘둘러 "젓가락처럼 뻣뻣하다"는 평을 받았습니다. 옆으로 미끄러져 나오고(기울기 6~9도), 고개·허리·팔을 시차를 두고 따로 움직입니다.

## 기본 캐릭터

`lib/figure-reader.ts`입니다. 비니·오버핏 맨투맨·와이드 팬츠 차림이고, 여자 캐릭터는 긴 머리와 부드러운 얼굴만 다릅니다. 표정은 `calm`·`happy`·`yay`·`wow` 넷이고, `wow`만 눈썹을 올리고 옆에 놀람 선을 그립니다. 올린 눈썹도 비니 테두리(y 74~77)에 닿지 않게 둡니다.
