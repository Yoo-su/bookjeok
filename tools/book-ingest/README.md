# book-ingest — 신간 적재 도구

운영자가 필요할 때 로컬에서 돌리는 도구입니다. 고른 출판사의 최신 도서를
공급처(카카오 또는 알라딘)에서 훑어 **`books`에 없는 책만** 골라, 표지를 R2에 올린 뒤
`books`에 넣습니다. 서버·웹 코드와는 별개이고 배포하지 않습니다.

배경과 결정 근거는 [계획서 6-d](../../docs/book-data-migration-plan.md)에 있습니다.

## 공급처

화면 상단 토글이나 CLI `--source`로 고릅니다. 키가 없는 공급처는 화면에서 비활성입니다.

|                   | 카카오 (`kakao`, 기본)               | 알라딘 (`aladin`) — **2026-10-30 종료**              |
| ----------------- | ------------------------------------ | ---------------------------------------------------- |
| 출판사당 조회     | 최대 20페이지(1,000권)               | 최대 4페이지(200권)                                  |
| 표지              | `t1.daumcdn.net` 원본, 392~458px     | `cover500`, 500px (없으면 원래 주소로 폴백)          |
| 책소개            | 약 250자, 문장 중간에서 잘림         | 적재 때 ItemLookUp으로 전문(출판사 소개 우선)        |
| `salesPoint`      | NULL                                 | **알라딘 판매지수**                                  |
| 저자 표기         | 원어·약칭이 섞임(`Kobo Abe`, `괴테`) | 한국어 정식 표기(`아베 코보`, `요한 볼프강 폰 괴테`) |
| 적재 때 추가 호출 | 없음                                 | 한 권당 ItemLookUp 1회 (일일 쿼터 5,000)             |

**10/30까지는 알라딘을 권합니다.** 판매지수가 함께 들어가 검색 순위에서 밀리지 않고,
표지·소개·저자 표기가 모두 낫습니다. 다만 알라딘 출판사 검색은 200권까지만 주므로
오래된 누락분은 카카오로 훑어야 합니다. 두 공급처 모두 `books`에 넣는 형식은 같습니다.

## 처리 순서

```
출판사·공급처 선택
 → 공급처 조회 (출판사 최신순, 끝 또는 공급처 상한까지)
 → 정제 · 제외 규칙
 → books 대조 (ISBN-13·10 모두) → 신규만
 → [적재] 공급처 보강 조회(알라딘: ItemLookUp — 긴 소개·판매지수)
        → 표지 원본 다운로드 → .data/originals 보관 → 가공(7-e 스펙)
        → R2 covers/{isbn}.{webp|jpg} 업로드 → 공개 URL 200 확인
        → INSERT … ON CONFLICT (isbn) DO NOTHING
```

- **R2가 먼저, DB가 나중입니다.** `books.image`에 벤더 URL이나 깨진 링크가 들어가는 순간이 없습니다.
- **이미 있는 R2 키는 덮어쓰지 않고 재사용합니다.** 표지가 `immutable`로 캐시되므로 덮어써도 반영되지 않습니다.
- **`books`에는 SELECT와 INSERT만 합니다.** UPDATE·DELETE·DDL은 없습니다.

## 준비

1. 의존성 설치: 저장소 루트에서 `pnpm install`
2. `packages/core` 빌드(정제 함수를 가져다 씁니다): `pnpm build --filter=@bookjeok/core`
3. `tools/book-ingest/.env.example`을 `.env`로 복사해 채웁니다. 같은 이름이 없으면 루트 `.env`에서 읽습니다.

| 변수                                                      | 용도                                                  | 필요한 명령          |
| --------------------------------------------------------- | ----------------------------------------------------- | -------------------- |
| `KAKAO_REST_API_KEY`                                      | 카카오 책 검색. 로그인용 `KAKAO_CLIENT_ID`와 다릅니다 | `--source kakao`     |
| `ALADIN_TTB_KEY`                                          | 알라딘 Open API. 루트 `.env`의 값을 그대로 읽습니다   | `--source aladin`    |
| `INGEST_DATABASE_URL`                                     | 운영 DB(Supabase 풀러)                                | 전부                 |
| `R2_ACCOUNT_ID`·`R2_ACCESS_KEY_ID`·`R2_SECRET_ACCESS_KEY` | 표지 업로드                                           | apply (serve의 적재) |
| `R2_BUCKET`                                               | 기본 `bookjeok-covers`                                |                      |

**자격증명은 권한을 좁혀 발급하세요.** R2 토큰은 `bookjeok-covers` 버킷 한정
Object Read & Write로, DB는 `books`에 SELECT·INSERT만 있는 전용 역할로 만드는 것을
권장합니다. 두 머신(맥·회사 윈도우)에 같은 값을 두게 되기 때문입니다.

서버·웹이 쓰지 않는 값이라 `turbo.json`의 `globalEnv`에는 등록하지 않았습니다.

## 쓰는 법

저장소 루트에서 실행합니다(`pnpm ingest`는 이 도구의 `ingest` 스크립트로 넘깁니다).

```bash
# 화면 — 공급처와 출판사 칩을 고르고 "신간 찾기" → 확인 후 "선택 N권 적재"
pnpm ingest serve

# 찾기만 (쓰기 없음). --source 기본은 kakao
pnpm ingest scan --source aladin --publishers 민음사,창비

# 찾은 신간 전부 적재. --yes 없이는 목록만 보여 주고 멈춥니다
pnpm ingest apply --source aladin --publishers 민음사 --yes

# 특정 책만
pnpm ingest apply --publishers 민음사 --isbn 9788937477515 --yes
```

화면에서 할 수 있는 것:

- **결과 거르기·정렬** — 제목·저자 검색, 예약판매 숨기기, 정렬(공급처 순서·출간일·판매지수·제목).
  판매지수 정렬은 알라딘 결과에서만 켜집니다. **적재는 화면에 보이는 선택만** 합니다.
  숨겨진 선택은 하단 바에 따로 표시됩니다.
- **카드 상세** — 카드를 누르면 서지·판매지수·카테고리·ISBN·책소개·공급처 원본 링크를
  봅니다. ←/→로 앞뒤 책, 체크박스로 적재 대상을 바꿉니다. 선택은 카드 왼쪽 위 체크박스
  (또는 카드에 초점을 두고 Space)로 합니다.

화면은 `127.0.0.1:4700`에만 열립니다. 다른 사이트가 브라우저를 통해 적재를
일으키지 못하도록 Host 헤더를 검사하고, 실행마다 새로 만드는 토큰을 요구합니다.

**처음 운영 DB에 돌릴 때는** `scan`으로 결과를 확인하고, `apply --isbn`으로 한 권만
넣어 상세 페이지(`/ko/book/{isbn}/detail`)에서 표지·서지를 확인한 뒤 늘리세요.

## 정제 규칙

| 필드          | 카카오                                                                            | 알라딘                                                                                |
| ------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `isbn`        | 13자리. DB에 ISBN-10으로만 있는 책도 "보유"로 봅니다                              | 같음. `K…` 내부 코드는 ISBN-10으로 쓰지 않습니다                                      |
| `title`       | HTML 엔티티만 풉니다. 공백·괄호 정리는 하지 않습니다(검색 쪽 `search_key`가 맡음) | 같음                                                                                  |
| `author`      | **저자만, 이름 그대로 `", "`로 연결.** 역자 없음. 비면 빈 문자열                  | 같음. 역할 괄호를 풀어 `옮긴이`만 빼고 나머지(지은이·엮은이·그림 등)는 저자           |
| `discount`    | `price`(정가)                                                                     | `priceStandard`(정가)                                                                 |
| `pubDate`     | `datetime` 앞 10자. `Date`로 파싱하지 않습니다(KST 하루 밀림)                     | `pubDate` 그대로                                                                      |
| `description` | `contents`. 약 250자에서 문장 중간에 잘림                                         | `fullDescription2` → `fullDescription` → `description` (기존 `books`와 같은 우선순위) |
| `image`       | `https://cdn.bookjeok.com/covers/{isbn}.{ext}`                                    | 같음                                                                                  |
| `salesPoint`  | NULL (0은 "판매 실적 없음"이라는 다른 뜻)                                         | 알라딘 판매지수. 0도 그대로 0                                                         |

**공통 제외:** 다른 출판사, 제목 없음, ISBN-13 없음, 잡지(977 ISSN — 호끼리 같은 값을 써서
PK 충돌), **978·979가 아닌 13자리**(`209…` 유통사 바코드 — 달력·굿즈), 세트, 정가 0 이하,
원본 표지 URL 없음. **예약판매는 포함합니다.**

**카카오만:** 판매 상태 없음, **판매가 -1(전자책·비매품).** 카카오는 전자책을 종이책과 섞어
주며, 주요 6개 출판사 최신 293건 중 100건(34%)이 전자책이었습니다(2026-09-23, 알라딘
`mallType`으로 대조). 전자책은 종이책 1~2달 뒤 별도 ISBN으로 나와 이미 가진 책이 신간처럼
보입니다. **알라딘만:** 성인 도서(`adult`).

표지는 카카오가 썸네일 URL의 `fname`에 든 `t1.daumcdn.net` 원본(폭 392~458px), 알라딘이
`cover500`(500px)입니다. 후보를 앞에서부터 받아 보고 실패하면 다음 후보를 씁니다.
JPEG는 WebP q85로 바꾸되 PSNR 30dB 미만이거나 오히려 커지면 원본을 그대로
올립니다. WebP 원본은 재인코딩하지 않습니다.

## 산출물 — `.data/` (gitignore)

| 경로                      | 내용                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------- |
| `runs/{시각}-scan.jsonl`  | 조회한 모든 문서의 판정(신규·보유·제외+사유)과 **공급처 원본 문서 전체**(`source`·`raw`)        |
| `runs/{시각}-apply.jsonl` | 적재 결과(표지 키·받은 주소·원본 크기·PSNR·재사용 여부)와 공급처 원본. 알라딘은 ItemLookUp 응답 |
| `originals/{isbn}.{ext}`  | 표지 원본. 가공 스펙을 바꾸면 여기서 다시 뽑습니다                                              |
| `favorites.json`          | 화면의 즐겨찾기 출판사                                                                          |

공급처 원본(카카오 `authors[]`·`translators[]`, 알라딘 `author` 문자열과 `categoryName`)이
JSONL에 남으므로, 표기 규칙을 바꿀 때 공급처를 다시 부르지 않고 이 파일에서 다시 만들 수
있습니다. 알라딘 종료 뒤에는 이것이 유일한 사본입니다. 머신마다 따로 쌓입니다.
2026-09-23 이전 기록은 원본이 `raw`가 아니라 `kakao` 키에 있습니다.

## 알아둘 것

- **검색 개선 작업의 `search_key` DDL과 동시에 돌리지 마세요.** 그 DDL은 `books`를
  다시 쓰며 테이블 전체를 잠급니다.
- 카카오 약관(저장·캐싱 범위)은 아직 확인하지 않았습니다(계획서 6-d 표의 3번).
- 새로 넣은 책은 임베딩이 없어 AI 추천에 나오지 않습니다(의도된 상태). 카카오로 넣은 책은
  판매지수가 없어 검색·인기순 뒤쪽에 섭니다. 키워드 검색에는 바로 나옵니다.
- 알라딘 판매지수는 적재 시점의 값이고 갱신되지 않습니다(8-c 「얼어붙는 스냅샷」).

## 알라딘 제거 (2026-10-30 이후)

알라딘 코드는 공급처 파일 하나에 모여 있습니다. 공통 코드와 화면에는 알라딘 분기가 없습니다.

1. `src/sources/aladin.ts`와 `src/__tests__/aladin.test.ts`를 지웁니다.
2. `src/sources/index.ts`에서 `aladinSource` import와 `SOURCES` 항목을 뺍니다.
3. 이 README의 「공급처」 표·정제 규칙·이 절에서 알라딘을 지우고, `.env.example`의
   `ALADIN_TTB_KEY` 안내를 지웁니다.
4. `pnpm --filter @bookjeok/book-ingest test`·`typecheck`로 확인합니다.
   (2026-09-23에 1·2만 적용해 타입체크와 나머지 테스트가 통과하는 것을 확인했습니다.)

기존 적재분과 `.data/runs`의 알라딘 원본은 그대로 둡니다.

## 테스트

```bash
pnpm --filter @bookjeok/book-ingest test       # 공급처별 정제·스캔·표지 가공·적재 순서·서버 보호
pnpm --filter @bookjeok/book-ingest typecheck
pnpm --filter @bookjeok/book-ingest lint
```

카카오·알라딘·R2·DB는 테스트에서 가짜로 바꿉니다. 표지 가공 테스트만 `sharp`로 실제 이미지를 만듭니다.
